### [dotfiles](https://github.com/saranyoopkp/dotfiles) — instruction architecture for coding agents

Cross-cutting rules, domain skills with explicit routing, versioned agent
definitions that separate implementation from acceptance review, and an
evaluation harness that indexes my own session transcripts.

I built it for my own work, then measured whether it actually changed how I
work — corrective turns dropped between 25% and 42% depending on how you
define a correction, at flat input effort.

**→ [How I measured it, and what I would still verify](https://gist.github.com/saranyoopkp/d3cbf6ad3a308aa089441e1c10c75d6d)**
